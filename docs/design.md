# Дизайн SyToDo

Согласованный стиль: «clinical blueprint on frosted paper», монохромный интерфейс
в духе shadcn/ui / Vercel. Mobile-first, спокойные поверхности, тонкие границы,
крупные скругления и компактная типографика. Поддерживаются обе темы Telegram.
Точные действующие значения находятся в [src/styles.css](../src/styles.css).

| Основной текст | `#0a0a0a` | `#fafafa` |
| Вторичный текст | `#737373` | `#a3a3a3` |
| Граница | `#e5e5e5` | `#303030` |
| Поле ввода | `#f5f5f5` | `#262626` |
| Текст основной кнопки | `#fafafa` | `#0a0a0a` |
| Удаление / ошибка | `#e7000b` | `#ff5c64` |

Основная кнопка использует ink как фон, вторичная — мягкий серый фон.
Красный только для удаления и ошибок. Никаких цветных брендовых акцентов,
градиентов, фотографий, иллюстраций или цветных теней.

## Типографика, формы и размеры

- Geist Variable, размещён локально через `@fontsource-variable/geist`, включая кириллицу.
- Основной текст 14 px/1.43; поля 16 px, чтобы iOS не увеличивал страницу при фокусе.
  Подписи и счётчики 12 px; не уменьшать основной текст до размера подписи.
- Вес 400/500/600. Заголовки 24–48 px в зависимости от viewport,
  tracking от −0.025 до −0.05em; uppercase-подписи до +0.05em.
- Карточки: radius 24 px, hairline 1 px. Контролы, кнопки, поля, badges: radius 18 px.
- Базовый шаг 4 px, обычные отступы 8/12/16/20/24 px. Карточки обычно 20 px.
- Тень светлой карточки: `0 0 0 1px rgba(23,23,23,.05), 0 1px 3px rgba(0,0,0,.1), 0 1px 2px -1px rgba(0,0,0,.1)`.
- Ширина страницы до 1280 px; на телефоне одна колонка. Проверять 320 px
  без горизонтального скролла, safe area и вертикальную прокрутку форм.
- Кнопки действий обычно от 44 px по высоте. Иконки — тонкие геометрические SVG
  из `src/icons.tsx`; цвета ink/muted, красный у удаления.

## Компоненты и взаимодействия

Шапка SyToDo, профиль и переключатель «Задачи / Напоминания» общие.
Внутри — карточки, счётчики, фильтры, понятные загрузка/ошибка/пустой список.
Создание, редактирование и подтверждение удаления открываются в `Sheet.tsx`
с доступным dialog, фокусом и Telegram BackButton.

`DateTimePicker.tsx`: собственный календарь, понедельник первым днём,
выбор месяца/года, «Сегодня / Завтра», выделение сегодняшней и выбранной даты.
Время — две вертикальные scroll-snap колонки (24 часа / 60 минут), строка 40 px,
5 видимых строк, выбранная строка в центре; поддерживаются touch и клавиатура.
Использовать эту компоненту и для задач, и для напоминаний.

`ReminderTiming.tsx`: готовые интервалы и поле собственного количества минут.
`RepeatFields.tsx`: режим повторения и 7 кнопок дней недели с aria-pressed.
Всё использует общие CSS tokens. Не заменять календарь native datetime-local
или иной визуально несогласованной компонентой без запроса пользователя.

Тема реагирует на Telegram themeChanged (`useTelegram.ts`), цвета Telegram chrome
согласуются с интерфейсом. Сохранить visible focus, клавиатуру, reduced motion,
safe area, обработку ошибок и блокировку повторных мутаций.
Не помещать технические термины SDK/SQLite/CLI в продуктовые формы.

## Проверка дизайна

`npm run test:ui` проверяет обе темы, колонки времени, настройки повторений,
CRUD и ширину 320 px. Скриншоты создаются в gitignored `test-results/`;
они не являются постоянными файлами документации. После UI-изменения проверять
актуальные скриншоты и переполнение длинных русских подписей.
